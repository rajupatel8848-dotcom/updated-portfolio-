# Aditya Patel — Creative Developer Portfolio

A static portfolio (HTML + CSS + vanilla JS — no libraries) with a small serverless **contact API**
that emails every message to you. No build step, no npm dependencies.

---

## 1. Run it locally

    node server.js            # http://localhost:3000   (needs Node 18+)
    # or, to test the contact form without sending real email:
    npm run dev               # same, but messages are only logged (MAIL_DRY_RUN=1)

Open `index.html` directly if you only want to look at the front-end (the contact form then falls back to
opening the visitor's email app, because there is no server to talk to).

## 2. Deploy (recommended: Vercel, free)

1. Push this folder to a GitHub repo (the `.gitignore` already keeps secrets out).
2. On vercel.com → **Add New → Project** → import the repo → **Deploy**. (Framework preset: *Other*.)
   Vercel automatically turns `api/contact.js` into the endpoint `/api/contact`.
3. Make the contact form deliver mail — get a free key at **resend.com** (API Keys → Create), then in
   Vercel → *Project → Settings → Environment Variables* add:

| Name | Value |
|---|---|
| `RESEND_API_KEY` | your key (`re_...`) |
| `CONTACT_TO` | the inbox that should receive messages |

   Redeploy once. Test the form on the live site — the message arrives in your inbox with *Reply-To* set to the
   visitor, so you just hit reply.
   *Note:* until you verify your own domain in Resend, its sandbox sender can only deliver to the email you
   signed up with — so use that address for `CONTACT_TO`.
4. Optional variables (see `.env.example`): `CONTACT_FROM`, `SEND_AUTOREPLY=true` (thank-you email to the
   visitor, needs a verified domain), `NOTIFY_WEBHOOK_URL` (Discord/Slack ping), `ALLOWED_ORIGIN`.

Other hosts (Render, Railway, a VPS): run `node server.js` with the same environment variables — it serves
the site and the API together.

## 2b. If only the HTML shows up on Vercel (plain text, no styling or animation)

**Cause:** Vercel received only `index.html`, not the folders next to it (`css/`, `js/`, `assets/`, `api/`). This happens
when files are uploaded one by one (GitHub's *Upload files* from a phone does not upload folders), when the **zip itself**
is uploaded instead of its contents, or when Vercel's *Root Directory* points at the wrong folder.

**Check in 10 seconds** (replace with your address): open `https://YOUR-SITE/css/styles.css` — you should see CSS text; if it
says 404, the folders are missing. Open `https://YOUR-SITE/api/contact` — you should see `Method not allowed` (that means the
contact backend is live).

**Fix — pick one**

1. **Laptop + GitHub (best):** unzip, open the folder that contains `index.html`, select *everything inside it* and drag it into a
   new GitHub repo (or use GitHub Desktop / `git push`). In Vercel: *Add New → Project → import the repo*; **Framework Preset: Other**;
   **Root Directory: `./`**; leave Build Command and Output Directory empty; Deploy.
2. **Vercel CLI (no GitHub):** `npm i -g vercel`, then inside the unzipped folder run `vercel --prod`.
3. **Only a phone / can only upload a few files:** use the one-file build — `portfolio-single-file.zip` (or run `npm run build:single`
   and use the `dist/` folder). It has the whole site inside **one `index.html`** plus `api/contact.js`. On GitHub use
   *Add file → Create new file*, type `api/contact.js` as the name (the slash creates the folder) and paste the file's contents.

Before you deploy, run `npm run check` in the folder: it lists anything that is missing.

## 3. Set your real domain (SEO + link previews)

The share-card image, canonical URL, sitemap and `robots.txt` contain the placeholder `https://YOUR-DOMAIN`.
After you know your URL run:

    npm run set-domain -- https://your-domain.com

## 4. What the contact API does (`api/contact.js`)

Validates name / email / message, ignores bots (hidden honeypot field), limits each visitor to 5 messages per
hour, escapes everything it puts in the email, blocks header-injection, and returns clear errors to the form.
If the server can't be reached the form still works by opening the visitor's email app.

## 6b. Landing page (dots to portrait)

White dots drift freely like stars on black. As you scroll they swirl together and settle into a black-and-white dot portrait of
you, then your name and buttons fade in. Scrolling back up scatters them again. Desktop mice gently push the dots aside.
Phones and tablets use fewer dots (about 5,000 instead of 14,000) and the page thins them out further on its own if a device
is slow. With "reduce motion" turned on, the finished portrait is shown still. Without JavaScript a plain portrait is shown.
To use a different photo: `python3 tools/make_hero_dots.py path/to/photo.jpg` (a front-facing head-and-shoulders photo works best).

## 7. Speed on phones, tablets and laptops

`js/perf.js` picks a tier on load: **full** on desktops, **lite** on phones, tablets and low-end laptops, and it
drops to **ultra** automatically if frames get slow. Lite/ultra show only the panels and discs you can see, skip
heavy shadows and glare layers, cache scroll positions (no layout reads while scrolling), cap pixel ratios and run
idle loops at 30 fps — the Education and Skills & Work sections measured about 2–4× smoother this way.
To compare tiers on any device add `?perf=full`, `?perf=lite` or `?perf=ultra` to the URL.

## 7b. Intro, sounds, footer balls, colours

- **Intro (loader):** the first thing visitors see. Scrolling (wheel, swipe, arrow/space keys) flies the camera through a desk scene into the
  monitor, the screen types a greeting, then it pixel-dissolves into the portfolio. "Skip intro" (or Esc) skips it. It is skipped
  automatically when "reduce motion" is on. Add `?noloader` to the URL while developing. Change the typed text in `js/loader.js`
  (the `SEG` array); the scene itself is the inline SVG at the top of `index.html` (`#ld`).
- **Click sounds:** `js/sound.js` makes a soft pop on every click/tap. The speaker button in the nav mutes it (remembered per browser).
- **Footer balls:** `js/footer-balls.js`. Colours are in the `COL` array; ball count and size are set in `spawn()` / `size()`.
- **Colour palette:** deep navy `#080D1A` / `#0E1526`, light text `#E8EDF7`, accents orange `#FF6B2C` / `#FF8A3D` and amber `#FFB347`.
  The Education cards use their own colour pairs in `js/journey.js`. Skill images: `assets/images/skill-01…06-*.webp` (shown in slides 01–06).

## 8. Quick menu

Press **Ctrl/Cmd + K** (or **/**) anywhere — or tap the ⌘ button in the floating dock — to jump to any section, copy
the email, download the résumé and more.

## 9. Accessibility and motion

A "Skip to content" link, keyboard access for the envelope and dock, and `prefers-reduced-motion`
support (the landing dots, envelope, video loop and footer character all switch to calm static versions).
